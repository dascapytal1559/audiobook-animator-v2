# A15: The planner proposes each scene's visual mode, and a user can override any scene.

**Status.** Standing.

**Decision.** The planner proposes each scene's visual mode, and a user can override any scene. Graphic illustration is a useful starting point for concrete subjects; poetic abstraction is useful for ideas and emotional passages. These are suggestions, not mandatory rules.

**Why.** Supports the autonomy target while preserving the user's creative control over individual scenes.
