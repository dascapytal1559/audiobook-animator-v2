# A20: Time on the timeline is stored as integer samples on the clip's own clock, zero at clip start.

**Status.** Standing.

**Decision.** Time on the timeline is stored as integer samples on the clip's own clock, zero at clip start. Seconds are derived for display.

**Why.** Consistent with the sample-exact splitting already done.
