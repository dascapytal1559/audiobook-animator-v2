# A5: Completion requires verified outputs, and verified work should be reusable on reruns.

**Status.** Standing.

**Decision.** Completion requires verified outputs, and verified work should be reusable on reruns.

**Why.** The autonomy target depends on detecting failure and avoiding unnecessary repeated work.
