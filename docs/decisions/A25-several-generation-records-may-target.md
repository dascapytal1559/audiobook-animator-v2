# A25: Several generation records may target the same time.

**Status.** Standing.

**Decision.** Several generation records may target the same time. The decisions file records which candidate is selected; unselected candidates remain visible as alternatives. Selecting is a decision, not a deletion.

**Why.** Preserves generated work and supports comparison.

**Cited by.** `packages/domain/src/shots.ts`
