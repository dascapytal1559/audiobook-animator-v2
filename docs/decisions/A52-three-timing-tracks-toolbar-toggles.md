# A52: Three timing tracks with toolbar toggles: Original (transcriber, read-only, faint), Auto (scripted, read-only), Edited (effective; the one selected and dragged, never empty).

**Status.** Standing.

**Decision.** Three timing tracks with toolbar toggles: Original (transcriber, read-only, faint), Auto (scripted, read-only), Edited (effective; the one selected and dragged, never empty). Clicking a word in any track seeks to that track's time.

**Why.** The user wants the original and the scripted result visible for reference.
