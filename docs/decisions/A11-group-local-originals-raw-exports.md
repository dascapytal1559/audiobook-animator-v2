# A11: Group local originals and raw exports under each book's `input/` directory, with `data/inbox/` for new downloads.

**Status.** Standing.

**Decision.** Group local originals and raw exports under each book's `input/` directory, with `data/inbox/` for new downloads. Separate the current source location from unchanged historical evidence and verified content identity.

**Why.** Moving an identical input should preserve completed transcription and splits without rewriting their provenance.
