# A2: One application with focused modules.

**Status.** Standing.

**Decision.** One application with focused modules. Each exposes validated inputs, outputs, and failures; Effect services handle media tools, storage, and providers.

**Why.** Keeps modules independently callable and gives external dependencies explicit boundaries.
